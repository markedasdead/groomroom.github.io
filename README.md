для того, чтобы открыть сайт нужно использовать **xampp** или **mamp**; 

1. скачайте ZIP с гитхаба
2. распакуйте архив
3. в xampp или mamp через расположение файла найдите папку **htdocs**, в нее перенесите разархивированную папку
4. запустите xampp/mamp
5. в браузере перейдите на http://localhost:8888/groomroom/index.php
